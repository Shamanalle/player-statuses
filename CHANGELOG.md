# Changelog

All notable changes to this project are documented in this file. Each version is written in English
first, then in Russian. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project uses [Semantic Versioning](https://semver.org/).

Все заметные изменения проекта записываются в этот файл. Каждая версия описана сначала на английском,
затем на русском.

## [Unreleased]

### English

#### Added
- First version of the mod for Fabric and Quilt (Minecraft 1.21.9 – 26.3), Forge (1.20.1, 1.21.9 – 26.3) and NeoForge (1.20.1, 1.21.1, 1.21.9 – 26.3), and a plugin for Paper, Purpur, Folia and Spigot servers (1.16.5 – 26.3).
- `/playerstatuses` shows the version, how many players have the mod and the server's settings; `/playerstatuses reload` reads the settings file again.
- `/afk` marks you AFK until you move. Servers can turn it off, and then another plugin's `/afk` keeps working.

### Русский

#### Добавлено
- Первая версия мода для Fabric и Quilt (Minecraft 1.21.9 – 26.3), Forge (1.20.1, 1.21.9 – 26.3) и NeoForge (1.20.1, 1.21.1, 1.21.9 – 26.3) и плагин для серверов Paper, Purpur, Folia и Spigot (1.16.5 – 26.3).
- `/playerstatuses` показывает версию, сколько игроков с модом и настройки сервера; `/playerstatuses reload` перечитывает файл настроек.
- `/afk` отмечает вас АФК, пока вы не сдвинетесь. Сервер может её выключить, и тогда работает `/afk` другого плагина.
