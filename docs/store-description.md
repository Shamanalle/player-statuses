# Store pages / Страницы на площадках

**English** · [Русский](#русский)

## English

Projects on CurseForge (and optionally Modrinth later) are created by hand; this file contains everything their forms ask for. Once a project exists, put its ID into `.github/publish.json` (see CONTRIBUTING, *CurseForge and Modrinth*), and the release workflow uploads the files automatically. Leaving `"modrinth": ""` in `.github/publish.json` skips Modrinth cleanly while publishing to CurseForge and GitHub Releases.

The store descriptions live in `docs/curseforge.html` (mod) and `docs/curseforge-plugin.html` (Paper / Purpur / Folia / Spigot plugin) — paste them into CurseForge's description editor via source view (`<>`). If you later publish to Modrinth, `docs/modrinth.md` and `docs/gallery.json` are uploaded automatically by the *Modrinth page* workflow.

### Name

**Name (both CurseForge Mods and CurseForge Bukkit Plugins):** Player Statuses: Typing, AFK, Inventory & Voice Chat Indicators

Why: stores search the project name and summary first, so the exact terms players type ("typing", "AFK", "inventory", "voice chat", "indicators") belong right after the colon — matching *Mob Senses* and *Chat Items*. Loaders and Minecraft versions are not allowed in store titles, so both the mod project and the Bukkit plugin project use the exact same title while differentiating loaders in their summaries.

**CurseForge Projects:**
- **Mod (`1797144`):** https://www.curseforge.com/minecraft/mc-mods/player-statuses-typing-afk-inventory-voice-chat
- **Bukkit Plugin (`1797163`):** https://www.curseforge.com/minecraft/bukkit-plugins/player-statuses-typing-afk-inventory-voice-chat

### Summary

**Summary:** See what players are up to: chat typing indicator, open inventory or chest, crafting, AFK timer, Alt-Tab & Simple Voice Chat mute icons — above heads and in the Tab list, with per-status privacy switches. Forge, NeoForge, Fabric & Paper.

237 characters (CurseForge allows 250, Modrinth 256).

**Plugin summary:** See what players are up to: chat typing, open inventory or chest, crafting, AFK timer & Simple Voice Chat icons above heads and in Tab — works with modded and vanilla clients! Server plugin for Paper, Purpur, Folia and Spigot.

226 characters (CurseForge allows 250).

**First paragraph of the description** (if creating a project before pasting the full HTML):

> See what other players are up to. A crisp dark-slate badge above a player's head shows when they are typing, have their inventory or a chest open, are AFK (with a timer) or have tabbed out, and the same shows in the Tab player list. The text you type is never sent, and every category of status has its own privacy switch in the in-game settings screen. A lightweight alternative to What Are They Up To (WATUT) for 1.16.5 – 26.3 on Fabric, Quilt, Forge and NeoForge, plus a Paper / Purpur / Folia plugin that also shows statuses to vanilla clients.

### Environment and dependencies

- **Environment:** Client & Server (icons require the mod on the client and the mod or plugin on the server; either side alone loads safely and stays silent).
- **Dependencies:** Fabric API (required, Fabric file only). Simple Voice Chat is optional and not listed as a required dependency.
- **License:** MIT. **Source:** https://github.com/Shamanalle/player-statuses · **Issues:** https://github.com/Shamanalle/player-statuses/issues

### Icon and gallery

`icon.png` in the repository root (512×512 pixel art, generated by `python3 docs/make-icon.py icon.png common/src/main/resources/assets/playerstatuses/icon.png`). The GitHub social preview is `docs/images/social-preview.png` (1280×640, *Settings → General → Social preview*). Both it, `docs/images/banner.png` and `docs/images/gallery/cover.png` are rendered from `docs/gallery/social.html` by `docs/gallery/make-banners.js`.

### Checklist for CurseForge setup

1. CurseForge → *Minecraft → Mods → Create project*: use the name, summary, `icon.png` and categories above; paste `docs/curseforge.html` via the `<>` HTML source view. Copy the numeric *Project ID* into `.github/publish.json` → `"curseforge"`.
2. CurseForge → *Minecraft → Bukkit Plugins → Create project*: use the plugin name above and paste `docs/curseforge-plugin.html` via `<>`. Copy its *Project ID* into `"curseforge_plugin"`.
3. Add repository secrets `CURSEFORGE_TOKEN` (one token covers both CurseForge projects) and `REPO_ADMIN_TOKEN` (see CONTRIBUTING). Leave `"modrinth": ""` as long as Modrinth is not used.
4. Upload the images from `docs/images/gallery/` (`cover.png` first, then `store-typing.png`, `store-inventory.png`, `store-crafting.png`, `store-container.png`, `store-afk.png`, `store-settings.png`) to each CurseForge project's *Images* tab.

### Чек-лист выкладки на CurseForge

1. CurseForge → *Minecraft → Mods → Create project*: название, краткое описание, `icon.png` и категории выше; вставьте `docs/curseforge.html` через кнопку исходного HTML (`<>`). Числовой *Project ID* впишите в `.github/publish.json` → `"curseforge"`.
2. CurseForge → *Minecraft → Bukkit Plugins → Create project*: название плагина выше и HTML из `docs/curseforge-plugin.html` через `<>`. Его *Project ID* впишите в `"curseforge_plugin"`.
3. Добавьте секреты репозитория `CURSEFORGE_TOKEN` (один токен подходит для обоих проектов CurseForge) и `REPO_ADMIN_TOKEN`. Поле `"modrinth": ""` оставьте пустым, пока Modrinth не используется.
4. Загрузите изображения из `docs/images/gallery/` (сначала `cover.png`, затем `store-typing.png`, `store-inventory.png`, `store-crafting.png`, `store-container.png`, `store-afk.png`, `store-settings.png`) во вкладку *Images* каждого проекта на CurseForge.
