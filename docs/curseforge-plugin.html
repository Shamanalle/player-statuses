Official server plugin for Player Statuses — one lightweight JAR for Paper, Purpur, Folia, Spigot, and Bukkit (Minecraft 1.16.5 – 26.3, Java 8+).

What Does This Plugin Do?

  • Full relay for modded clients: relays real-time status icons (typing, command entry, inventory, containers, workstations, reading, AFK timer, unfocused window, and Simple Voice Chat mute/deafen icons) between players running the Player Statuses client mod on Fabric, Quilt, Forge, or NeoForge.
  • Built-in bridge for vanilla clients: players without the mod are not left out! The server automatically detects AFK time and open containers (chests, barrels, shulker boxes, crafting tables, furnaces, enchanting tables, anvils, villagers, lecterns) for unmodded players and displays statuses to vanilla clients via:
    • Overhead TextDisplay labels above players' heads on Minecraft 1.19.4+ (automatically hidden from modded players so badges never double up, and respecting sneaking, invisibility, spectator mode, and scoreboard team nametag visibility).
    • Clean status suffixes in the Tab player list across 1.16.5 – 26.3.
  • Native Folia & Vanish support: uses region-safe entity scheduling on Folia and respects vanish plugins (SuperVanish, PremiumVanish, EssentialsX, CMI, and Player#canSee) so vanished staff never leak statuses or overhead entities.

Commands & Permissions

  • /playerstatuses — shows plugin version, modded player count, active server settings, and your current status (localized in each player's own game language across 13 supported languages).
  • /playerstatuses reload (permission: playerstatuses.admin, default: op) — reloads plugins/PlayerStatuses/playerstatuses-server.properties on the fly (changes are also picked up automatically within ~2 seconds).
  • /afk (permission: playerstatuses.afk, default: true) — marks the player AFK until they move or act. Registered dynamically only when afk_command=true, so setting afk_command=false leaves EssentialsX or CMI's /afk untouched.

Configuration (plugins/PlayerStatuses/playerstatuses-server.properties)

  • afk_command=true — enable or disable the built-in /afk command.
  • detect_players_without_mod=true — detect AFK and open containers on the server for players without the client mod.
  • afk_minutes=5 — idle minutes before an unmodded player is marked AFK (1 – 120).
  • vanilla_overhead=true — show overhead TextDisplay statuses to vanilla clients on 1.19.4+.
  • vanilla_tab_list=true — show status suffixes in the Tab list when vanilla clients are online.
  • language=en_us — language used for console replies and server-wide vanilla TextDisplay / Tab labels (13 built-in locales).
