Server plugin for Player Statuses (Paper, Purpur, Folia, Spigot, Bukkit 1.16.5 – 26.3).

  • Relays status icons (typing, inventory, chests, crafting, AFK timer, tabbed out, voice chat state) between players who have the Player Statuses client mod on Fabric, Quilt, Forge or NeoForge.
  • Works for vanilla clients too: detects AFK and open containers on the server side and displays statuses above players' heads (1.19.4+ TextDisplay) and in the Tab player list, localized in each player's game language.
  • Folia-ready and works on every Bukkit/Spigot/Paper server from 1.16.5 to 26.3 on Java 8+.

Commands, permissions and configuration: GitHub README.
